# Раздельные dev-диагностики партии и боя

`party-tactics-probe-0.1.0` проверяет Luna, Sol и Astra в одинаковых условиях
Codex CLI с `low`, с записью и replay каждого решения. Доступна история ходов,
инструменты запрещены и их использование проверяется по событиям Codex; полной
изоляции файловой системы нет. Испытания являются вручную заданными случаями,
поэтому никаких оценок качества на популяции миров не дают.

**Выбор партии.** Один видимый бронированный противник и один слот. Игрок
выбирает защитника, лекаря или мага; правила боя и характеристики показаны.
Зачёт означает, что для выбранного состава BFS движка находит победную
стратегию. Он не измеряет, сможет ли модель её исполнить. В этом конкретном
примере решением является маг: остальные роли заведомо не выигрывают; это
ограничение набора, а не вывод о непригодности других классов.

**Тактика.** Состав фиксирован — лекарь и маг. Доступны три фиксированные
конфигурации: `one`, `two`, `three` врага с одинаковыми характеристиками.
Модель выбирает каждое действие, включая способ, персонажа и цель. Исход,
раунды, HP героя, нанесённый урон, лечение, использованные заряды и количество
ошибочных действий записываются отдельно. Ограниченный BFS нашёл решения во
всех трёх случаях. Варианты отвечают только за число врагов; они не являются
независимыми случайными мирами.

В каждой комбинации оси и уровня запускается по одному экземпляру на модель.
`seed` не изменяет случай; повторные seed не должны считаться независимыми
сценариями. Запусков holdout нет. Технические остановки не являются поражением.
Для статистической оценки нужны новые, разнообразные и заранее зафиксированные
встречи, в которых полезны разные роли.

Из корня workspace:

```sh
python3 scripts/three_model_party_tactics.py init party-case --axis party --level fixed
python3 scripts/three_model_party_tactics.py run party-case
python3 scripts/three_model_party_tactics.py init tactics-three --axis tactics --level three
python3 scripts/three_model_party_tactics.py run tactics-three
python3 scripts/three_model_party_tactics.py status tactics-three
python3 -m unittest scripts.test_three_model_party_tactics -v
```

`init` и `status` не обращаются к моделям; `run` выполняет реальные вызовы.
Исходные планы и приватные журналы хранятся вне репозитория. Версии кода,
Codex и условия закреплены fingerprint; неопределённые вызовы не повторяются
автоматически. Следите за отдельным числом завершённых партий и за тем, что
фактически измеряет каждое условие.
