# Параллельный исполнитель полного приключения

`scripts/parallel_gradient_calibration.py` — отдельный протокол для **будущих**
планов. Он не изменяет и не продолжает старые результаты. Промпт, настройки
моделей, мир, правила и скорер наследуются от `gradient-codex-calibration`;
добавлено до трёх независимых одновременно выполняющихся CLI-вызовов.
Координатор владеет блокировкой плана и единолично обновляет state с атомарной
записью; в любой момент не более одного незавершённого вызова на эпизод.
Каждая партия воспроизводится из действий при старте и перед её следующим ходом.

Непосредственно перед отправкой в журнал записывается `inflight`. Если
процесс завершается посередине вызова, он остаётся неопределённым и следующий
автоматический запуск не допускается; запрос нельзя незаметно повторять.
Партии с выявленной технической ошибкой не повторяются, остальные продолжают.
Ограничение числа вызовов учитывает все зарегистрированные попытки, включая
незавершённые. Входные токены проверяются перед отправкой по известным usage;
порог может быть превышен числом токенов до трёх одновременно отправленных
вызовов. Это не денежный лимит. По истечении времени новые запросы не
начинаются, уже начатые дожидаются завершения или своего timeout.

Сетевые ошибки, скорость и порядок получения ответов могут отличаться от
последовательного прогона: признак параллельности нужно сохранять в отчёте.
Исследовательские данные разных конфигураций и версий не усредняют. Сиды и
трассы остаются в отдельном приватном каталоге. Holdout требует фиксации плана.

```sh
python3 scripts/parallel_gradient_calibration.py init next-hard
python3 scripts/parallel_gradient_calibration.py run next-hard --split dev
python3 scripts/parallel_gradient_calibration.py status next-hard
python3 -m unittest scripts.test_parallel_gradient_calibration -q
```

Тесты проверяют одновременные вызовы, уникальность попыток, непродолжение
неопределённого `inflight` и сохранение незавершённых эпизодов при достижении
ограничения числа запросов. Они не являются тестами поведения моделей.
