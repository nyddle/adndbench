# Экспериментальные пробы механик (mechanics probes)

`benchmark/mechanics_probes.py` — отдельное семейство контрольных вопросов о
числовых правилах боя, построенных только из сообщений, которые модель
фактически видела в партии. Модуль не подключён к `benchmark/runner.py` и
`benchmark/scoring.py`; показатель `mechanics_inference` не смешивать с
другими пробами.

## Мотивация

Существующие пробы проверяют память и пространство, но не обучение из опыта.
В протоколе **скрытых правил** системный промпт не содержит чисел боёвки:
модель может узнать стоимость отступления, цену защиты или урон усиленной
атаки только по исходам своих действий. Вопрос после партии измеряет, вывела
ли она правило из наблюдений.

## Построение

Из трассы берутся пары «действие → сообщение в следующем наблюдении». По
каждому факту (обычная атака, атака после защиты, ответ пережившего
противника, стоимость отступления, стоимость защиты) вопрос задаётся, только
если все наблюдённые значения совпадают: дракон с чередованием фаз или ноль
вместо ответа автоматически исключают вопрос. Эталон — число; `check_answer`
требует, чтобы ответ содержал ровно это число и никакое другое.

## Ограничения

- Под полным системным промптом (где все числа перечислены) пробы измеряют
  чтение инструкции, а не вывод из опыта. Осмысленный режим — скрытые правила;
  версию промпта фиксировать в отчёте, результаты режимов не смешивать.
- Состав вопросов зависит от того, какие события встретились в партии модели;
  сравнивать модели можно только с отчётом о числе заданных вопросов.
- Факт «атака после защиты» определяется по действию `defend` на предыдущем
  ходу; если сценарий усиливает атаку иначе, вопрос просто не возникает.

Тесты `tests/test_mechanics_probes.py` проверяют извлечение фактов, фильтр
конфликтующих и нулевых значений, пропуск ненаблюдавшихся фактов и строгость
проверки ответа.
