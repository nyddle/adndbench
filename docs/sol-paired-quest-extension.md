# Sol на ранее пройденных dev-мирах квестов

`scripts/sol_paired_quest_extension.py` добавляет GPT‑6.2 Sol к уже завершённым
парным dev-партиям Luna и Astra из плана `radical-quest`. Это разведочное
сравнение трёх моделей на одних и тех же мирах, не независимая финальная оценка.

```sh
python3 scripts/sol_paired_quest_extension.py init radical-quest-sol --source radical-quest
python3 scripts/sol_paired_quest_extension.py run radical-quest-sol
python3 scripts/sol_paired_quest_extension.py status radical-quest-sol
```

`init` читает исходный приватный план только для проверки, сверяет исходный
fingerprint и воспроизводит сохранённые dev-ходы обеих моделей. Он требует, чтобы
все их dev-партии были завершены. В новый план копируются только dev-сиды и
агрегированные исходы; holdout-сиды не копируются и этот runner не имеет команды
для их запуска. Копия включает исходные правила, окно контекста, effort `low`,
версию CLI и все лимиты. SHA dev-спецификации и журналов фиксируют происхождение;
прежние файлы не меняются. Созданный план повторно использовать для другого
набора, модели или изменённого кода нельзя.

Каждый запрос в новой серии резервируется до отправки. Повтор неопределённого
вызова блокирован; техническая ошибка не считается игровым поражением. Результат
Sol появляется в status рядом с исходами Luna и Astra без приватных сидов и
полных журналов. Это повторяемый эксперимент через Codex CLI с аудитом
инструментальных вызовов, но без полной файловой изоляции; он не равен прямому
OpenAI API. Ограничения по токенам оцениваются между запросами и не являются
лимитом оплаты. Условия и приватное хранение описаны в
[paired-codex-calibration.md](paired-codex-calibration.md).

Офлайн-тесты: `python3 -m unittest scripts.test_sol_paired_quest_extension -v`.
