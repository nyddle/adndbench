# Трёхмодельный пилот: hard-квесты в полной игре

Условия зафиксированы до запросов: три новых исследовательских мира, в каждом
одинаковые для Luna, Sol и Astra, `reasoning_effort=low`; память medium, карта
easy, квесты hard, бой medium, наём включён, игровой предел 160 ходов и вся
история до 160 действий. Это новое условие, его нельзя объединять с предыдущим
пилотом medium-квестов. Для нового условия также созданы три отложенных мира;
до выбора и фиксации протокола они не используются для настройки.

Сценарий, протокол промпта и оценка идентичны базовому gradient runner, но
исполнитель запускает партии независимо: **технический сбой закрывает только
его эпизод и никогда не перезапускается**; остальные модели и миры продолжают.
Неопределённый незавершённый вызов (`inflight`) блокирует автоматическое
возобновление всего запуска. Внешние лимиты вызовов, входных токенов и времени
останавливают запуск; незавершённые результаты остаются `null`, а не нулём
или поражением. После остановки по ограничению времени можно продолжить уже
начатые известные партии с проверкой воспроизведения и без повтора вызовов.
Бюджет на split: до 1000 вызовов и 20 млн входных токенов; проверка токенов
идёт перед вызовом, один вызов может превысить границу. Это не денежный лимит.

Перед модельными испытаниями привилегированный oracle на 100 открытых
контрольных мирах выполнил 100/100 за 55–83 хода (среднее 69,5), зная карту,
код, оптимальную цепочку и оптимальное поведение в бою. Это только контроль
существования решений на этих мирах, а не предсказание результатов моделей.

```sh
python3 scripts/independent_gradient_calibration.py init full-hard-3
python3 scripts/independent_gradient_calibration.py run full-hard-3 --split dev
python3 scripts/independent_gradient_calibration.py status full-hard-3
```

Все сиды, действия и протокол воспроизведения лежат только в приватном
каталоге пользователя. Любой публичный отчёт должен включать плановое и
завершённое количество игр, отдельно исходы и характеристики, и не публиковать
сиды или полные трассы. Не считать средний балл только завершившихся эпизодов
репрезентативным без учёта причин незавершения. См.
[методику базового протокола](gradient-codex-calibration.md).
